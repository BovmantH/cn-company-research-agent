# Triage Labels

| Matt 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格充分，可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工操作或判断 |
| `wontfix` | `wontfix` | 决定不处理 |

技能提到 triage 角色时，使用本表右栏标签。若仓库已有不同标签体系，只修改右栏映射，不改变角色语义。
